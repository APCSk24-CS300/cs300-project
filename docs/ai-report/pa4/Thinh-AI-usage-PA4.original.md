**How this file was made**
- **Prompts.** They come from the Claude Code session transcript for this project (`~/.claude/projects/E--HCMUS-Third-Year-HK1-CS300---SE-project-project-cs300-project/*.jsonl`), using only entries with `type == "user"` and a string `message.content`. Tool results, slash commands and system messages (task notifications, interruptions, compaction summaries) are excluded. Times are converted from UTC to UTC+7.
- **Quotes.** Prompts are quoted verbatim. Long prompts keep their first sentence followed by "…". The `<pasted_content>` wrapper the terminal adds around pasted text is not part of the quote.
- **Commits** come from `git log --all --date=iso`. A commit is matched only when it follows the prompt within a few hours and its content matches the requested work. Otherwise the entry says "no commit".
- **"AI …"** describes only the spec/plan files the session created or edited, according to the Write/Edit tool calls in the transcript.
- **"The student …"** is a placeholder for the student to fill in.
